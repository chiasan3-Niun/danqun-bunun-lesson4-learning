# 互動語言學習網站製作

用使用者提供的教材與素材，建立一個可直接開啟、可部署分享的原生 HTML/CSS/JavaScript 學習網站。

## 核心規則

- 只使用使用者提供或明確核准的教材內容；不要自行創作族語詞彙、句型、翻譯、文化說明或音檔內容。
- 先做自學，再解鎖闖關評量。自學區至少能翻卡、播放音檔、查看中文或句型分析；自動播放再次按下要能取消。
- 每一個族語單字或句子使用相對應圖片，不可用同一張圖取代所有字卡。人物、服裝與畫風要保持一致；若使用者要求一般學生服裝，不能擅自改成傳統服飾。
- 音檔只使用使用者提供的檔案或使用者指定的合成服務。播放速度依需求設定；播放失敗要保留文字活動，不要把不存在的音檔說成已完成。
- 選擇題選項要隨機，但同一正確答案位置不可連續重複。遊戲要有可見的正確／錯誤結果、計分與完成條件。
- 句型題要依教材的句型公式、詞塊與圖意設計；若使用者指定克漏字，就用克漏字，不改成句子排序。
- 顯示教材來源與著作權時，照使用者指定文字呈現，不自行添加不確定的授權條款。

## 建議工作流程

1. 先盤點使用者提供的教材、圖片、音檔、詞彙、例句、句型公式與版權文字，列出缺漏；不補寫未知內容。
2. 建立 `data/lesson.js`，讓教材資料與互動程式分開。每筆資料保留來源識別與素材路徑。
3. 以 [references/site-contract.md](references/site-contract.md) 檢查自學、解鎖、評量、回饋、計分、重學與響應式需求。
4. 從 [assets/template](assets/template) 複製 buildless 起始結構，再依教材內容修改；不要引入不必要的框架或套件。
5. 用瀏覽器實際測試翻卡、自動播放取消、音檔按鈕、每種題型、計分、結果重學與行動版畫面。
6. 使用者要求發布時，確認 GitHub remote 與分支，只提交本網站相關檔案，建立新 commit、推送 GitHub、由 Vercel 部署，最後用瀏覽器確認正式網址。

## 交付內容

至少交付：可開啟的 `index.html`、相對路徑的素材、教材資料檔、清楚的 README、測試結果與共享網址（若使用者要求發布）。

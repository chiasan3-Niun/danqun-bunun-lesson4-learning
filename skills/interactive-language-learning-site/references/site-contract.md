# 網站功能契約

## 自學區

- 詞語卡：圖片、族語、中文翻卡、單字音檔、例句音檔（若有）。
- 句型卡：句型公式、詞塊拆解、完整句意與例句音檔（若有）。
- 聽讀卡：依教材提供的聽力或閱讀材料呈現。
- 自動播放：播放目前素材後自動前進；再次按鈕要停止排程與音檔播放。

## 闖關區

- 自學完成後才解鎖第一關，完成一關才解鎖下一關。
- 題目可隨機出現；選項順序要避免正確答案連續固定在同一位置。
- 評量要顯示答對或答錯、累計答對與答錯數，並在最後提供學習結果與薄弱知識點。
- 「重新學習」清除本課數據；「繼續累積」保留原有數據。
- 句型題依公式與圖片完成句子；克漏字題只挖空教材詞語，不把文法分析當作答案。

## 內容與權利

- 不得把推測內容當作教材。
- 未提供音檔時，使用待補狀態並保持可操作的文字題。
- 頁尾分開列出網站設計、頻道、語音合成、文本來源、編輯單位與教材出處；文字完全依使用者核定版本。
